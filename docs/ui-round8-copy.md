## 组件

| 组件 | 文件 | 说明 |

| `Select` / `SelectOption` | `components/ui/select.tsx` | Radix Select。保留 `<option>` 子元素与 `value` / `onChange(e)`（`e.target.value` 即选项 value，空字符串选项照常可用），因此替换原生 select 不改变取值语义。胶囊触发器（`rounded-full`、`bg-surface-2`、chevron），浮层 `bg-surface` + 边框 + `shadow-pop` + `rounded-2xl`，选项有内边距、当前项右侧对勾、可选 `description` 副标题；超长列表在浮层内滚动，靠视口边缘自动翻转；键盘：方向键 / Home / End / 输入首字 / Enter / Esc（焦点回到触发器）。必须有可访问名称：`aria-label`、`aria-labelledby` 或 `id`（配合 `<Label htmlFor>`），类型上强制。触发器带 `data-value`（当前值），选项带 `data-value` / `data-label`，供测试使用。 |
| `Switch` | `components/ui/switch.tsx` | Radix Switch（`role=switch`、`aria-checked`、Space/Enter 切换）。开启为 `--info` 蓝（浅色 #2458c6 / 深色 #7aa2f7，对 surface 均 > 4.5:1），关闭为灰底 + `--fg-subtle` 描边与圆点，状态不只靠颜色。`busy`：旋转图标 + `aria-busy` + 暂时禁用；`invalid`：红色描边 + `aria-invalid`；`disabled`。过渡只改颜色/位移，`prefers-reduced-motion` 与应用内“减少动效”由全局规则关闭。必须有可访问名称（类型强制）。命中区域扩展到 ≥ 40px。 |

| `SettingsGroup` / `SettingsRow` / `SettingsContent` / `SettingsNav` | `components/ui/settings.tsx` | ChatGPT 式设置布局：内容列 ≤ 720px，分组标题 + 细分隔线行，左侧标签（+一行提示 / `help`），右侧控件右对齐；`SettingsNav` 为左侧导航（手机上变为横向滚动条）。 |

## 控件转换决定

转换为 Switch（真正的两态、即时生效的设置）：

- 设置：减少动画、动态点阵背景
- 预算：启用；自动化：启用；技能：启用；连接：我的任务可用
- 运行环境：允许项目单独选择、各服务商“启用”、允许内网地址
- 模型：允许成员自带密钥、服务“启用”、模型“对成员开放 / 启用”、“不需要密钥”、“使用 OpenAI 新版对话接口”、列表筛选“只看已开放”
- 审计：显示技术详情；权限视图：只显示已拥有；环境变量：锁定（组织级）

保持为 checkbox（原因）：

- 权限矩阵（含“全选”半选）、模型可见范围（部门 / 成员）、思考强度、模型能力勾选、挑选要启用的模型、助手工具 / 知识库、自动化通知渠道：多选列表或半选，不是两态设置
- 运行环境“我确认：文件和命令会发送到云端”：同意类确认，保留 checkbox 语义
- 清除已保存的密钥、审核“强制发布”：一次性危险动作的确认，不是持久设置

### 有意保留（可见）
- 权限与风险：高危 / 敏感徽标、授予高危角色与设置所有者 / 管理员的确认文案、“你没有修改该成员角色的权限”、“你只能看到自己所管理部门范围内的成员”。
- 成本与数据外发：“厂商云：数据会离开组织”、“我确认：工作区里的文件和命令会发送到该服务商的云端”、项目“远程位置的数据可能离开组织”、自带密钥“内容会直接发给你填写的地址，费用由你的服务账户承担”、技能“加载技能只提供说明，不授予任何权限…”、连接审核中的后果说明。
- 不可逆 / 危险操作：停用、移出组织、删除角色 / 部门 / 用户组 / 服务 / 凭据的确认弹窗与后果；一次性显示的邀请链接 / 触发地址。
- 安全限制：默认位置测试失败时“不会自动改用本机沙箱”；新增可见提示“「禁止联网」尚未验证，请不要依赖它隔离网络”（不再只藏在能力表里）。
