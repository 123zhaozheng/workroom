# Workroom 设计与文案规范（第 5 轮冻结，集成者维护）

面向普通企业员工的在线工作 Agent。参考：LambChat 的克制、Apple HIG 的清晰层级、细微状态动效。

## 文案
- 默认不写解释性副标题；页面标题 + 必要的一行说明最多。说明放到 `?` 提示、空状态或“了解更多”折叠里。
- 不在普通界面出现内部实现词：pi-ai、provider、pi-durable、namespaces、driver、fixture、SSE、DTO、taskId、callId、JSON、sha256、requestId 等。管理员高级区可在“技术详情”折叠中展示。
- 保留：安全与决策信息（审批的实际操作/范围/风险、权限高危标记、数据会离开组织的提示）、明确的错误原因与恢复动作、空状态说明。
- 用词统一：模型（不说渠道/provider）、服务商、工作区（不说沙箱目录）、成果/文件、技能、连接（MCP 仅在管理员详情出现）。动词按钮 2–4 字：允许、拒绝、重试、继续、下载、预览。
- 测试模型标注保留且只出现一次：“测试模型”。模拟用量标“模拟”。

## 排版与间距（Tailwind 类，保持一致）
- 字号：页面标题 `text-xl font-semibold`；区块标题 `text-sm font-medium`；正文 `text-sm`（14px）；辅助 `text-xs text-fg-muted`；不使用 <12px 文本。
- 间距：4 的倍数；卡片内边距 `p-4`；区块间距 `space-y-6`；表单行 `gap-3`。
- 圆角：控件 `rounded-lg`，卡片/浮层 `rounded-xl`；阴影只用 `--shadow-pop`（浮层）与 `--shadow-composer`（输入框）。
- 颜色：文字只用 `--fg / --fg-muted / --fg-subtle`（均已达 WCAG AA）；状态色 good/bad/warning 只用于状态，不做装饰。

## 交互
- 浮层（菜单、下拉、弹窗）背景必须不透明 `bg-surface` + 边框 + `--shadow-pop`；动画只做 opacity/transform ≤150ms，结束态完全不透明；不得遮挡标题栏，靠视口边缘自动翻转。
- 所有可点击元素键盘可达（Tab/Enter/Space/Esc），焦点环 `focus-visible:ring-2`；图标按钮必须有 `aria-label`。
- 动效：仅表达状态（进行中、完成、出错）；`prefers-reduced-motion` 与应用内“减少动效”时禁用；点阵背景保留可关闭。
- 深色模式：所有新组件使用 token，不写死颜色。
- 响应式：1440 / 1366 / 390 必测；390 下侧栏与预览改为抽屉，菜单改为底部弹层，禁止横向滚动。

## Agent 体验（参考 Agentic UX patterns）
- 工具调用按一次运行聚合为一行紧凑状态（“已完成 3 步 · 生成 1 个文件”），展开后才见步骤；每步用人话摘要（“检索知识库：回款率”），原始参数/结果只在“技术详情”。
- 审批卡：做什么（具体对象）、影响范围、风险等级、允许/拒绝（仅后端支持的选项），默认焦点不在“允许”。
- 运行中可插话；失败给出原因与“重试/继续”；分支切换保持。
- 用户消息中的测试指令 `[[...]]` 不作为普通文本展示（显示清洗后的文本，测试标记以小徽标呈现）。
